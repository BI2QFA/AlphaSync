# AlphaSync

**AlphaSync** 是一套面向**索尼老相机**的无线传图工具，由「相机端」与「手机端」两个应用配合工作：相机端打开无线服务后，手机端即可**发现、浏览、预览、下载**相机存储卡中的照片与视频，并支持**边拍边传** —— 新拍摄的照片自动同步到手机。

## 功能

- **配对相机**
- **更加智能的缩略图加载机制**
- **直接传输SD卡内的文件，如RAW原图**
- **相机端支持连接已有Wi-Fi或启动热点**
- **支持后台运行边拍边传**

## 兼容性

所有能安装软件的**索尼全画幅/APS-C相机**均可使用。
